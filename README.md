 🤖 AI-Powered Interview Preparation Platform

An advanced full-stack web application designed to help tech aspirants crack technical interviews using automated, real-time AI mock tests. Built with an **Angular** frontend, a scalable **Spring Boot** backend, and integrated with **Google Gemini AI**.

---

🚀 Key Features
* AI Mock Interviews: Generates dynamic, domain-specific technical questions on topics like Java, Spring Boot, Angular, and SQL.
* Smart Performance Evaluation: Leverages Google Gemini AI to analyze user responses and provide instant, constructive feedback.
* Past Questions Tracking: Saves previous interview history and responses for easy revision and structured learning.
* Interactive Dashboard: Clean, user-friendly UI with responsive performance metrics.

---

 🛠️ Tech Stack & Architecture

 💻 Frontend
* Framework: Angular 17+
* Styling: CSS3, Responsive Layouts
* Build Tool: Angular CLI

 ☕ Backend
* Core Framework: Spring Boot 3.x
* Language: Java 17+
* AI Integration: Google Cloud Gemini AI API
* Build Automation: Maven

🏃‍♂️ How to Run Locally

 1. Backend Setup (Spring Boot)
- Open the backend directory in IntelliJ IDEA.
- Add your Gemini API key in `GeminiService.java`.
- Run `AiPrepPlatformApplication.java`.

 2. Frontend Setup (Angular)
- Open the frontend directory in VS Code.
- Install dependencies: `npm install`
- Start the server: `ng serve`
- Open `http://localhost:4200/` in your browser.
